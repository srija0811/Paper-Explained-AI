# Paper Pal AI

Build a modern AI web application called "Paper Explained AI".

The application should have:

- Landing page with hero section

- Upload PDF button

- Drag and drop support

- Generate Explanation button

- Progress indicator

- Paper summary section

- Extracted figures section

- Generated narration preview

- Video preview section

- Download Video button

- Error page for unreadable PDFs

- Responsive design

- Modern blue/purple AI theme

- Tailwind CSS

- React + TypeScript

This project was built with [Lovable](https://lovable.dev).
